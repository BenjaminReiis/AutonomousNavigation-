# Autonomous Navigation System

## Descrição

Sistema profissional de navegação autônoma desenvolvido em Python, C++ e ROS2.

## Recursos

- Navegação autônoma
- Planejamento de rotas
- IA
- SLAM
- OpenCV
- YOLO
- LiDAR
- GPS
- IMU
- FastAPI
- React
- Docker
- PostgreSQL

## Estrutura

backend/
ai/
navigation/
slam/
sensors/
frontend/
mobile/

## Instalação

```bash
git clone https://github.com/SEU_USUARIO/AutonomousNavigation.git

cd AutonomousNavigation

pip install -r requirements.txt
```

Executar

```bash
uvicorn backend.main:app --reload
```
